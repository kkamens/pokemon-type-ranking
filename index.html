计算规则

  1. 倍率 → 得分：按 log2 计分，非 0 档取 ±0.5。
    倍率攻击得分防御得分
    4×+2.5−2.5
    2×+1.5−1.5
    1×00
    ½×−1.5+1.5
    ¼×−2.5+2.5
    0×−4.5+4.5
  2. 攻击得分：对 18 种防御属性逐项计分求和；双属性攻击取两属性中更有利者。
  3. 防御得分：对方 18 种属性攻击的倍率计分求和；双属性防御取两属性倍率之积。
  4. 综合 = 攻击得分 + 防御得分。
  5. 平衡 = −|攻击 − 防御|（越接近 0 越均衡）。
  6. 排名：按 综合 → 平衡 → 攻击 → 防御 依次比较；并列由排序键决出（速览表下划线标注），名次固定 171 项、不受筛选影响。
  7. 数据来源：官方属性相克表（第九世代，第六世代起未变），数值由脚本复算。

属性图标裁剪自公开素材合集（第三方来源）；代表宝可梦取该组合所有官方形态（含 mega、地区形态）中种族值最高者，特殊形态标注形态名（如 喷火龙-超级喷火龙Ｘ）；9 个组合无对应宝可梦，显示「无」。图片仅作展示引用。
