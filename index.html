关键结论

基于 171 种属性组合的纯倍率结果
属性边际贡献
钢的优势不是个别强配对，而是稳定抬升底盘

在全部 17 个含钢双属性中，平均综合为 24.46；其余双属性平均仅 12.40，差值达 12.06。综合前 20 名有 12 个含钢，说明钢带来的主要是可跨搭档复用的抗击端增益，而非少数偶然组合。

打击与抗击分工
地面推进打击前沿，钢控制抗击上限

含地面双属性的平均打击为 13.70，18 种属性中最高；含钢双属性的平均抗击为 16.41，同样居首。两者结合成地面／钢后，分别取得打击 14.79、抗击 16.00，是综合第二且高度均衡的组合。

帕累托前沿
真正不可被同时超越的组合只有五个

若要求不存在另一组合同时拥有更高打击和更高抗击，171 项中仅剩 幽灵／钢、地面／钢、地面／飞行、地面／岩石、冰／地面。它们构成从抗击极致到打击极致的完整效率边界。

双属性协同
双属性收益来自覆盖并集，且不是简单相加

153 个双属性的综合都高于各自两个单属性中更强者，平均提升 11.95；其中地面／飞行提升最大，达 22.47。原因是打击端逐目标取两种属性的更优倍率，形成覆盖并集，而抗击端又重新组合弱点、抗性与免疫。

攻守关系
高打击并不必然换来低抗击

153 个双属性中，打击与抗击的相关系数仅 −0.014，几乎没有线性关系；其中 127 个同时处于打击、抗击非负的双强区，没有任何双属性落入双弱区。规则空间允许通过搭配同时改善两端。

平衡指标解释
最平衡不等于最强，先看综合再看平衡才合理

共有 32 个组合的打击与抗击差值不超过 2，且全部为双属性。一般／水虽然差值为 0，但综合仅 12.00；地面／钢差值 1.21、综合却达 30.79。平衡只衡量两端接近程度，不能单独代表强度。

计算规则

  1. 倍率 → 得分：以 log₂(倍率) 为基础，并对非中性倍率沿正负方向额外修正 ±0.5，以放大覆盖范围的差异：奖励更广的有效打击面与抗击面，惩罚更窄的有效打击面与抗击面。具体对应关系见下表。
    倍率打击得分抗击得分
    4×+2.5−2.5
    2×+1.5−1.5
    1×00
    ½×−1.5+1.5
    ¼×−2.5+2.5
    0×−4.5+4.5
  2. 打击得分：对全部 171 种防守属性组合逐项计分；双属性作为打击组合时，对每个目标取两种属性中更有利的倍率。所得原始总分除以 9.5，折算为与 18 项抗击端相同的尺度。
  3. 抗击得分：面对 18 种单属性来袭逐项计分后求和。
  4. 综合 = 等效打击得分 + 抗击得分，两端权重相等。
  5. 平衡 = −|等效打击得分 − 抗击得分|（越接近 0 越均衡）。
  6. 百分制：综合、平衡、打击、抗击分别按全量 171 项线性归一化，最低值记为 0，最高值记为 100；筛选不会改变百分制，排序仍按原始分值进行。
  7. 全量数据表中并列时，按综合 → 平衡 → 打击 → 抗击依次比较显示位次。
  8. 数据来源：属性、形态与种族值基于 PokeAPI master-branch 固定快照 2fe9553（2026-10-07，REST API v2，包含《宝可梦传说 Z-A》数据）；属性相克倍率由本页固定矩阵计算，数值由脚本复算。
