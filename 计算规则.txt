规则
• 倍率 → 得分：以 log₂(倍率) 为基础，并对非中性倍率沿正负方向额外修正 ±0.5，以放大覆盖范围的差异：奖励更广的有效打击面与抗击面，惩罚更窄的有效打击面与抗击面。
• 打击得分：对全部 171 种防守属性组合逐项计分；双属性作为打击组合时，对每个目标取两种属性中更有利的倍率。所得原始总分直接作为打击得分，保留 171 项尺度。
• 抗击得分：面对 18 种单属性来袭逐项计分后求和，再乘以 9.5（171 ÷ 18），折算为与 171 项打击端相同的尺度。
• 综合 = 打击得分 + 等效抗击得分，两端权重相等。
• 平衡 = −|打击得分 − 等效抗击得分|（越接近 0 越均衡）。
• 百分制：综合、平衡、打击、抗击分别按全量 171 项线性归一化，最低值记为 0，最高值记为 100；筛选不会改变百分制，排序仍按原始分值进行。
• 全量数据表中并列时，按综合 → 平衡 → 打击 → 抗击依次比较显示位次。
• 数据来源：属性、形态与种族值基于 PokeAPI master-branch 固定快照 2fe9553（2026-10-07，REST API v2，包含《宝可梦传说 Z-A》数据）；属性相克倍率由本页固定矩阵计算，数值由脚本复算。
属性图标为透明底 PNG，裁剪自公开素材合集（第三方来源）；代表宝可梦按该快照全部官方形态的六项种族值总和取最高者，并列时保留现有代表。物种名采用 zh-hans 字段；该快照暂缺简体形态名的 Z-A 新增 Mega 形态，按英文 Mega 标识统一写作“物种名 - 超级物种名”，洗翠风速狗与洗翠索罗亚克则保留“洗翠的样子”。9 个组合无对应宝可梦，显示「无」。图片仅作展示引用。
